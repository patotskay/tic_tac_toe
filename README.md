# Крестики-нолики

Данная программа представляет собой игру крестики-нолики, которая запускается из терминала.
Игра реализована c помощью библиотеки tkinter. Игровое поле состоит из девяти интерактивных кнопок, при нажатии
на которые поочередно появляются крестики и нолики, в зависимости от хода. При выигрыше победная комбинация 
кнопок окрашивается зеленым цветом. Также есть кнопка начать заново, с соответствующим функционалом.
